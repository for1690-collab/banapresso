# 바나프레소 부천옥길점 매장 관리 웹앱 (PWA)

바나프레소 부천옥길점(매장코드 64800) 직원용 재고·발주·매장현황 PWA 런처 저장소입니다.

## 프로젝트 구성
- `index.html`: PWA 런처 (구글 앱스 스크립트 웹앱 임베드 및 반응형 뷰어)
- `manifest.json`: 사파리/크롬 홈 화면 추가 메타데이터
- `icon_pink.png`: 홈 화면 고화질 앱 아이콘
- `images/`: 신규 메뉴 및 매장 대표 이미지 에셋

---
*본 저장소는 바나프레소 부천옥길점 전용 독립 프로젝트로 운영되며, 타 프로젝트와 격리되어 관리됩니다.*
